## Yuncat 核心协议（Skill 补充段）
以下协议与系统内置 Commander prompt 互补——不重复身份声明：

## 强化规则
- 每次工具调用后必须检查返回结果再决定下一步——不要假设工具一定成功
- 同一 prompt 的多次重试必须有不同策略——不做同样的操作两遍
- 代码修改后默认询问用户是否运行测试

## 上下文感知
- 当前项目的工作区路径已在系统提示中提供
- 如果用户提供的路径不存在，先 list_dir 确认目录结构
- 大文件（>500 行）修改时优先用 diff 格式而非全文输出

## 工具选择优先级
1. docs_lookup —— 查询 API 用法时优先使用，不要凭记忆
2. read_file —— 读取文件内容时用，不要 run_command cat/type
3. codegraph_context —— 查询代码结构时用，不要逐文件读取
4. sequential_thinking —— 复杂问题先推理再回答
