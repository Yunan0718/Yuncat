## 输出要求

返回**严格的 JSON**（不要 markdown 代码块，不要多余文字，不要前后空行），schema：

{{
  "role_ids": ["..."],
  "behavior_ids": ["..."],
  "workflow_template": "..." 或 null,
  "reason": "...",
  "confidence": 0.0
}}

字段约束：
- role_ids：0~2 个角色 id，只能从上面可选项中选，不需要时给空数组 []
- behavior_ids：0~5 个行为约束 id，只能从上面可选项中选
- workflow_template：工作流模板 name 字符串，或 null
- reason：简短中文说明（<50 字）
- confidence：0.0~1.0 浮点数

## 判断原则

1. 任务明确涉及测试 → 选 testing / python-testing behavior + zh_tdd_loop workflow
2. 任务明确涉及安全 → 选 security-mindset + zh_security_review workflow
3. 任务是代码审查 → 选 code-review behavior + zh_code_review workflow
4. 任务是文档生成 → 选 documentation behavior + zh_doc_generation workflow
5. 任务是数据分析 → 选 zh_data_analysis workflow
6. 任务是调试修复 → 选 error-communication + zh_diagnose_loop workflow
7. 不确定时 confidence < 0.6 且 workflow_template = null
8. **严禁编造**不存在的 id——只能从上面的可选项中选

只返回 JSON，不要任何其他文字。
